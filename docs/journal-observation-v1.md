## 1. Primary Scientific Invariant: Journal ≠ Measurement

The fundamental scientific invariant of the PsycheAI reflection layer is:
> **"Kişisel günlük ve yansıma kayıtları öz-bildirimdir (USER_REPORTED_CONTEXT); asla psikometrik ölçüm (DIRECT_MEASUREMENT) yerine geçmez."**

### Invariants Enforced:
1. **Zero Scoring Impact**: Journal entries cannot compute, modify, or impute facet scores, construct scores, or domain composite scores.
2. **Zero Coverage Impact**: Journal entries cannot mark any `NOT_MEASURED` facet as `MEASURED`, nor change the total ontology facets denominator ($91$).
3. **Zero Longitudinal Interference**: Journal entries do not generate numeric trajectory delta points. They can only serve as contextual timestamp associations alongside longitudinal epochs.

## 2. Epistemic Taxonomy & Hierarchy

All psychological and narrative materials within PsycheAI enter under strict epistemic classifications:

| Evidence Class | Source | Authority Level | Can Alter Facet Scores? |
| :--- | :--- | :--- | :--- |
| `DIRECT_MEASUREMENT` | Psychometrically verified native research battery responses | 1 (Highest) | YES |
| `DETERMINISTIC_PATTERN` | Rule-based mathematical synergies & tensions between measured facets | 2 | NO |
| `USER_REPORTED_CONTEXT` | Free-text journal entries, self-report ratings (mood, energy, stress) | 3 | NO |
| `OBSERVATIONAL_DATA` | Repeated themes, contextual variations across multiple entries | 4 | NO |
| `AI_REFLECTIVE_HYPOTHESIS`| Exploratory insights generated by DeepSeek or fallback | 5 | NO |
| `THEORETICAL_INTERPRETATION`| Epistemic lenses (Freud, Jung, Rogers, Adler, etc.) | 6 | NO |

## 3. Data Models & Database Storage

### A. JournalEntry
- `id`: CUID
- `userId`: CUID (Foreign key to `users.id`, with `ON DELETE CASCADE`)
- `title`: String?
- `body`: Text (Untrusted user input, prompt injection protected)
- `entryType`: Enum (`FREE_REFLECTION`, `EVENT`, `EMOTION`, `DECISION`, `RELATIONSHIP`, `WORK`, `GOAL`, `STRESS`, `SUCCESS`, `CHALLENGE`, `OTHER`)
- `moodSelfReport` / `energySelfReport` / `stressSelfReport`: Integer? ($1 \le x \le 5$, validated server-side)
- `contextTags`: String[] (`GENERAL`, `WORK`, `RELATIONSHIPS`, `FAMILY`, `DECISION_MAKING`, `STRESS`, `SOCIAL`, `SELF_IMAGE`, `GOALS`, `HEALTH`, `LIFE_EVENT`)
- `userTags`: String[] (Unrestricted)
- `isLifeEvent`: Boolean
- `lifeEventType`: Enum? (`JOB_CHANGE`, `RELOCATION`, `RELATIONSHIP_TRANSITION`, `MAJOR_GOAL`, `HIGH_STRESS_PERIOD`, `OTHER`)
- `createdAt`, `updatedAt`, `deletedAt`: DateTime

### B. JournalInsight
- `id`: CUID
- `entryId`: Foreign key to `journal_entries.id` (`ON DELETE CASCADE`)
- `userId`: Foreign key to `users.id` (`ON DELETE CASCADE`)
- `insightType`: Enum (`ENTRY_REFLECTION`, `REPEATED_THEME`, `PROFILE_ALIGNMENT`, `CONTEXTUAL_VARIATION`, `DECISION_REFLECTION`, `EMOTIONAL_PATTERN_REFLECTION`, `GOAL_REFLECTION`, `LONGITUDINAL_CONTEXT_LINK`, `OPEN_QUESTION`)
- `evidenceClass`: `OBSERVATIONAL_DATA`
- `summaryTr`: Text (Turkish exploratory reflection)
- `reflectivePrompt`: Text? (Deeper self-inquiry question)
- `isFallback`: Boolean
- `engineVersion`, `promptVersion`, `provider`, `modelId`, `sourceContentHash`: Provenance metadata

### C. JournalProfileRelationship
- `id`: CUID
- `entryId`: Foreign key to `journal_entries.id` (`ON DELETE CASCADE`)
- `relationshipType`: Enum (`ALIGNED_WITH_MEASUREMENT`, `DIFFERS_FROM_MEASUREMENT`, `CONTEXTUAL_VARIATION`, `UNMEASURED_RELEVANT_AREA`, `NO_CLEAR_RELATION`)
- `evidenceType`: `OBSERVATIONAL_DATA`
- `strength`: Enum (`WEAK`, `MODERATE`, `STRONG` — represents evidence repetition, NEVER psychometric confidence)
- `relatedFacetIds`, `relatedConstructIds`, `relatedDomainIds`: String[] (strictly validated against $91$ active Master Facets)

## 4. Soft-Delete & Edit Invalidation Semantics

1. **User Delete Action**:
   - Executes in an atomic transaction:
     1. Verifies entry ownership.
     2. Deletes derived `journal_insights` rows.
     3. Deletes derived `journal_profile_relationships` rows.
     4. Sets `deletedAt = now()`.
   - All standard queries filter `deletedAt: null`. Soft-deleted entries never participate in theme calculation, AI payloads, or timeline cards.

2. **Edit Invalidation**:
   - When entry content or tags are edited:
     1. Verifies entry ownership.
     2. Updates `JournalEntry`.
     3. Deletes previous `journal_insights` and `journal_profile_relationships` rows.
     4. Generates fresh analysis asynchronously or on demand, preventing stale interpretations.
