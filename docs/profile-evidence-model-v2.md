## 4. Grounding Invariants for FAZ 2.18

1. **Explicit Provenance**: Every statement generated by an AI model regarding a trait must cite the `evidenceId` or `facetId` from the evidence bundle.
2. **Missing Data Transparency**: If a facet is marked `NOT_MEASURED`, the AI must explicitly acknowledge it as unassessed and must not guess or speculate on the score.
3. **Response Quality Awareness**: When `responseQuality.cautiousInterpretationRequired === true`, the AI must frame insights with epistemic caution and emphasize telemetry context.
4. **Theoretical Lens Translation**: Historical psychological frameworks (e.g. Jungian types, Adlerian style of life) can be used as interpretive lenses only, and cannot generate synthetic scores.
